Commandes disponibles

Scaffold le dossier company/
Crée les 29 fichiers de contexte (brand, stratégie, marketing, juridique). À faire une seule fois, avant /build-company.
/build-company
Lance (ou reprend) l'orchestrateur
Lit ton avancement, annonce la phase courante, appelle le bon agent, te demande de valider la gate. À lancer à chaque session de travail.
note: [idée]
Capture une note dans le backlog
Disponible à tout moment. La note est classée automatiquement dans la bonne phase (P0→P6) et atterrit dans BACKLOG.md. Voir la section ci-dessous.
go / pivot
Réponse à une gate
go = passer à la phase suivante. pivot = reboucler (souvent retour en phase 1 pour revalider). Tu peux aussi poser une question — l'orchestrateur creuse avant de passer.

Comment ça fonctionne

Règles d'abord

Les mots-clés de la note sont analysés instantanément (gratuit, sans appel LLM). "prix", "tarif" → Phase 4. "interview", "validation" → Phase 1.

LLM en fallback

Si les règles ne tranchent pas, Claude est appelé pour classer. Résultat : zéro note "non classée" dans BACKLOG.md.

Précaution de trigger

Le trigger est note: (avec deux-points). Une phrase comme "la note est de 5/10" ne déclenche rien. Utiliser note: uniquement en début de message.
